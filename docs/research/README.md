# Clinic interviews (YOS-5)

Anonymised notes only: no clinic names, staff names or patient details.

## Questions

1. What do you check in a patient file before an appointment?
2. Does this differ by appointment type (consultation, follow-up, specialist)?
3. Which documents are most often missing?
4. When do you usually find out something is missing?
5. How do you contact the patient today (call, SMS, WhatsApp)? In which language?
6. Who decides whether a message is sent?
7. How long does checking tomorrow's appointments take?
8. What tools do you use today (software, paper, Excel)?
9. What would you never want an automated system to do?
10. Would you try a tool like this? What would make you trust it?
